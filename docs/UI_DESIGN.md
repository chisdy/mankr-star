## 0. Design Read

> **Reading this as:** developer 向「个人 GitHub 收藏库」产品 UI（鉴权面 + 应用壳），受众是重度 Star 用户；气质偏 **Linear / Primer 式克制工具感**；设计系统锁定 **shadcn preset `b5ckO8Yzo`**，在其 token 上做布局与密度，而不是另起一套皮肤。

说明：taste-skill 主战场是 landing / portfolio。本产品主体是 **收藏库（偏工具壳）**，因此：

- **鉴权页**（注册 / 登录）：按营销面纪律做（品牌、留白、克制动效）。
- **应用内**（列表 / 筛选 / 详情）：提高密度、减少营销套路；禁止三列等宽 feature 卡、假截图、eyebrow 堆砌。

---

## 1. 三档旋钮（本项目取值）

| Dial | 值 | 理由 |
|------|----|------|
| `DESIGN_VARIANCE` | **5** | 工具产品优先可预期布局；鉴权页允许轻度不对称 |
| `MOTION_INTENSITY` | **4** | 进入过渡 + hover/active；不做卷轴大片 / 无限循环装饰动效 |
| `VISUAL_DENSITY` | **6** | 日常 App：列表可扫读，不是美术馆留白，也不是座舱仪表盘 |

## 2. 设计系统锁定

### 2.1 不可违背

```bash
pnpm dlx shadcn@latest init --preset b5ckO8Yzo --template vite --monorepo --pointer
```

- 颜色、圆角、字体、图标库以 **preset 生成结果为准**。
- 业务只组合 `packages/ui`；禁止并行引入另一套 DS（Fluent / Material / Carbon 等）。
- 禁止把组件停在「shadcn 默认演示态」：间距、层级、空态文案必须贴合 Mankr Star。

### 2.2 在 preset 之上的气质覆盖（文档级，实现时映射到 CSS 变量）

| Token 角色 | 意图 |
|------------|------|
| Surface | 偏冷的纸面 / 墨色（跟 preset 的 background / card 对齐，不另造奶油纸） |
| Text | 高对比正文；次要信息降一级，仍过 AA |
| Accent | **单一强调色**（实现时取 preset primary；禁止再叠第二套霓虹紫） |
| Border | 1px 分割优先于重阴影；卡片 elevation 少用 |
| Radius | 全站跟 preset 一套圆角，按钮 / 输入 / 面板不混用两套规则 |

**禁止默认 AI 套路：** 紫渐变英雄区、三列等宽卖点卡、玻璃拟态铺满、Inter 硬覆盖 preset 字体、hero 里塞 stats / logo wall。

### 2.3 图标

- 优先使用 **preset / shadcn 已配置的图标包**（若为 lucide，本项目可例外沿用，因脚手架绑定）。
- 全站统一 `strokeWidth`；禁止手绘装饰 SVG。

### 2.4 主题

- 支持 **light / dark**（跟 shadcn theme）；默认跟随系统。
- **整页单一主题**：应用壳内禁止某一 section 突然反相成另一套纸色。

## 3. 信息架构与导航

### 3.1 路由（与技术方案一致）

| 路由 | 角色 |
|------|------|
| `/register` | 仅实例无用户时可进 |
| `/login` | 日常入口 |
| `/` | 收藏库（主战场；左侧文件夹树筛选） |
| `/folders` | 重定向至 `/`（兼容旧链接） |
| `/feed` | 更新动态 |
| `/insights` | 库洞察与 AI 用量 |
| `/settings` | 账号与偏好 |
| 详情 | **抽屉优先**（桌面），小屏可全页 `/bookmarks/:id` |

### 3.2 应用壳导航

桌面单行顶栏或左侧窄轨（二选一，**实现选定左侧轨**，更适合工具类长时间停留）：

```text
┌────┬──────────┬────────────────────────────────────┐
│ MS │ 文件夹   │ Search……………………  [+ 添加]          │
│ ★  │ [+]      ├────────────────────────────────────┤
│ ⟳  │ ▾ AI     │                                    │
│ ⚙  │   Agent  │           主内容区                   │
│    │ ▸ 前端   │                                    │
└────┴──────────┴────────────────────────────────────┘
```

窄轨：收藏 / 动态 / 洞察 / 设置。文件夹树在窄轨右侧面板（Animate UI Files），CRUD 与筛选均在此完成。

规则：

- 导航桌面 **单行 / 单列可读**，高度 ≤ 80px（若用顶栏）。
- 主 CTA 文案统一：**「添加」**（不要同时出现「新建收藏」「添加链接」「Import」抢主按钮；导入放设置或添加对话框次级）。
- 当前路由用边条 / 字重表达，不用彩色圆点装饰。

## 4. 鉴权面（Register / Login）

### 4.1 构图（Asymmetric Split，VARIANCE 允许）

```text
┌──────────────────────┬──────────────────────┐
│                      │                      │
│  Mankr Star          │   创建账号 / 登录      │
│  管好你的 GitHub     │   ┌────────────────┐ │
│  Stars               │   │ 邮箱或用户名   │ │
│                      │   │ 密码           │ │
│  一句说明（≤20 词）  │   │ [主要按钮]     │ │
│                      │   │ 次要链接       │ │
│                      │   └────────────────┘ │
│                      │                      │
└──────────────────────┴──────────────────────┘
```

移动端：上品牌短句 + 下表单；`min-h-[100dvh]`，禁止 `h-screen`。

### 4.2 文案纪律（用户可见字符串）

| 位置 | 建议文案 |
|------|----------|
| 品牌 | `Mankr Star`（字号大于表单标题） |
| 副句 | `把 GitHub Stars 变成可检索的私人库。`（≤20 词） |
| 注册主按钮 | `创建账号` |
| 登录主按钮 | `登录` |
| 已有用户访问注册 | `此实例已初始化，请直接登录。` |
| 密码错误 | `账号或密码不正确。`（不暴露哪一侧错） |

禁止：版本号 eyebrow、`BETA` 徽章、Scroll 提示、装饰中点串、em dash 文案花活。

### 4.3 表单

- Label **在输入框上方**；错误在框下；禁用 placeholder-as-label。
- 主按钮对比度过 AA；`:active` 轻微 `scale-[0.98]`。
- Loading：按钮内 skeleton / disabled +「请稍候」，不用整页转圈盖住品牌。

### 4.4 动效（MOTION 4）

- 表单区一次 stagger fade-in（≤300ms，`prefers-reduced-motion` 时关闭）。
- 无无限脉冲、无磁性光标、无假终端预览。

## 5. 收藏库（主界面）

### 5.1 布局

```text
┌─ 工具条 ──────────────────────────────────────────┐
│ 筛选: 全部文件夹 ▾  标签 ▾  语言 ▾    排序: 最近 ▾ │
├───────────────────────────────────────────────────┤
│ 行 / 紧凑卡片列表（非三列营销卡）                    │
│ ┌─────────────────────────────────────────────┐   │
│ │ owner/repo          ★ 12k   TS    文件夹名     │   │
│ │ AI 一句话摘要……                              │   │
│ │ tag  tag  tag                                │   │
│ └─────────────────────────────────────────────┘   │
│ …                                                 │
└───────────────────────────────────────────────────┘
```

### 5.2 列表单元（Bookmark Row）

单行主信息层级：

1. **仓库名**（`owner/repo`）- 最强
2. **AI 摘要**（一行 truncate）- 次强
3. Meta：language、stars、文件夹、更新时间 - 弱

标签：最多展示 3–4 个，溢出 `+N`。

**不要做成：** 等大三列 feature 卡、每卡大插画、卡片外再套玻璃层。

### 5.3 添加收藏

- 主路径：顶栏 **「添加」** → Dialog / Sheet。
- 字段：URL 或 `owner/repo`；可选笔记。
- 提交后：列表乐观插入，`ai_status=pending` 时摘要位用 skeleton 行，完成后替换（Motion layout 可选）。

### 5.4 空态 / 加载 / 错误

| 状态 | 表现 |
|------|------|
| 空库 | 短标题 + 一句说明 + 唯一 CTA「添加」 |
| 加载 | 与最终列表同结构的 skeleton 行（禁止居中大 spinner 作为唯一反馈） |
| 错误 | 行内或顶栏 banner；可重试 |

空态文案示例：`还没有收藏。粘贴一个 GitHub 链接开始。`

### 5.5 搜索与筛选

- 搜索框常驻工具条；占位：`搜索名称、摘要、标签…`
- 筛选状态写入 **URL search params**（可分享、可返回）。
- 激活中的筛选用 chip 展示，可一键清除；chip 不是彩虹胶囊堆。

## 6. 详情（Drawer 优先）

```text
┌─ 详情 ─────────────────────────────┐
│ owner/repo                     ✕   │
│ 摘要（可编辑覆盖 AI）               │
│ 文件夹  [▾]   标签  [..]              │
│ 笔记                                │
│ 元数据：stars / language / pushed   │
│ 最近变更（小时间线）                 │
│ [打开 GitHub]  [归档]               │
└────────────────────────────────────┘
```

- 桌面：右侧 Sheet（约 420–480px）。
- 编辑即时保存或显式「保存」二选一；MVP 选 **显式保存** 防误触。
- 打开 GitHub：外部链接，新标签。

## 7. 文件夹树 / 动态页 / 设置

### 7.1 文件夹（侧栏树）

- **位置**：应用壳左侧，icon rail 旁的文件夹面板（桌面常驻；移动端在导航 Sheet 内）。
- **组件**：Animate UI `@animate-ui/components-base-files`（`Files` / `FolderItem` 嵌套树）。
- **交互**：点击文件夹名 → `/?folder_id=` 筛选右侧收藏列表；chevron 仅负责展开/折叠（与选中分离）。顶部「全部收藏」清除筛选。
- **管理**：面板内新建 / 编辑 / 新建子文件夹 / 删除。有子文件夹时点击删除会提示先处理子文件夹；有收藏时弹窗选择：取消归属 / 一并删除收藏 / 迁移到其他文件夹。颜色点仅表达文件夹色，全站仍只有一套 accent 用于交互控件。

### 7.2 动态（Feed）

- 时间线：日期分组；每条 `仓库 · 事件类型 · 时间`。
- 点击跳转详情抽屉。
- 空态：`暂无更新。开启跟踪的仓库出现变更后会显示在这里。`

### 7.3 设置

分区，用 `border-t` / 标题分隔，少用卡片套卡片：

1. 账号（用户名、改密、登出）
2. **DeepSeek**（API Key 输入、保存 / 清除、测试连接、模型选择 flash/pro；已配置时只显示尾号）
3. GitHub PAT（输入 + 保存 / 清除；永不回显完整明文）
4. 数据（导出 JSON、可选清空）
5. 外观（主题：系统 / 亮 / 暗）

## 8. 动效清单（必须可说出目的）

| 动效 | 目的 | 实现提示 |
|------|------|----------|
| 鉴权表单进入 | 层级：先看品牌再看表单 | Motion stagger，reduced-motion 关闭 |
| 列表项出现 | 状态：数据到达 | `whileInView` 或 query 成功后短 fade |
| 抽屉开合 | 状态切换 | Sheet 自带；勿再套一层花活 |
| 按钮 active | 反馈 | `scale-[0.98]` |
| 文件夹树展开 | 层级：展开子文件夹 | Animate UI Accordion / Files；reduced-motion 时缩短 |
| AI 摘要 skeleton → 文本 | 状态：生成完成 | 交叉淡化 |

禁止：第二处横向 marquee、GSAP 钉住长卷、自定义光标、滚动提示文案。

## 9. 响应式

| 断点 | 行为 |
|------|------|
| `< md` | 侧栏收成抽屉导航；列表全宽；详情改全页 |
| `md+` | 侧栏固定；详情 Sheet |
| 触控 | 列表行点击热区 ≥ 44px 高 |

布局用 Grid；禁止 `w-[calc(33%-1rem)]` 类 flex 百分比魔法。

---

## 10. 无障碍与质感底线

- 正文与控件对比度 ≥ WCAG AA。
- 焦点环可见（跟 shadcn focus-visible，不删）。
- 图标按钮必须有 `aria-label`（如关闭抽屉、打开菜单）。
- `prefers-reduced-motion: reduce` 时关闭装饰性过渡。
