# Mankr Star 浏览器扩展（MV3）

一个只有弹窗的最小扩展：把当前标签页地址交给你的 Mankr Star 实例，由 Web 应用弹出新增收藏框并预填链接。

## 为什么不直接调 API

`/api/*` 用的是同站 Cookie 会话。让扩展直接 POST 需要把会话带出扩展沙箱（跨站 Cookie 权限或长期令牌），维护成本远高于收益。跳转到 `{实例}/?add=<encoded url>` 复用了已登录的浏览器会话，未登录时还能自然走应用内的登录引导。

## 安装（开发者模式）

1. 打开 `chrome://extensions`，启用「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本目录 `apps/extension`
3. 首次使用在弹窗里填写实例地址（如 `https://star.example.com`），之后会记住。**请只填你自己部署的可信站点**——扩展会把当前页完整 URL 作为 `?add=` 传给该地址。

## 使用

在任意网页点击扩展图标 → 「在 Mankr Star 中添加」→ 新标签页打开实例并弹出新增框，链接已预填，可再选文件夹、写笔记后提交。

## 文件

| 文件 | 作用 |
|------|------|
| `manifest.json` | MV3 清单；权限只要 `activeTab` + `storage` |
| `popup.html` | 弹窗界面 |
| `popup.js` | 读取当前标签页、记住实例地址、拼 `?add=` 跳转 |
