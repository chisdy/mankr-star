# Mankr Star 浏览器扩展（MV3）

浏览任意网页时，如果它已经在你的 Mankr Star 里，工具栏图标会显示 ★。匹配在扩展本地完成，不会把每个浏览地址发到实例。

## 额度

扩展保存一份收藏身份表（编号、来源、规范化地址、外部编号、是否归档）。打开网页只查这张本地表。

身份没变时，启动、打开弹窗、以及大约每 30 分钟，只向实例核对一次版本号（`If-None-Match`，对上了就是 304）。只有新建、删除、归档、导入结束或 GitHub 仓库改名之后，才会重新下载身份表。

## 安装（开发者模式）

1. 打开 `chrome://extensions`，启用「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本目录 `apps/extension`
3. 首次使用在弹窗里填写实例地址（如 `https://star.example.com`），点按钮授权该站点。**请只填你自己部署的可信站点。** 请先在同一个 Chrome 里登录这个实例。

改了匹配规则后需要重新打包后台脚本：

```bash
pnpm --filter @mankr/extension build
```

## 权限

| 权限 | 原因 |
|------|------|
| `tabs` | 读取当前标签地址，才能在打开网页时标出是否已收藏。安装时会提示读取浏览记录 |
| `alarms` | 大约每 30 分钟核对一次版本号 |
| `storage` | 记住实例地址和本地身份表 |
| 可选的站点权限 | 只在你点按钮时授权所填的那一个实例，用来带上登录 Cookie |

## 使用

- 已收藏：图标显示 ★。弹窗里可以看到来源；点「打开收藏」进入 `/?bookmark=`。
- 未收藏：点「在 Mankr Star 中添加」，新标签打开实例并预填链接。
- 在网页里新收藏一条之后，打开扩展弹窗（或等到下一次版本检查），星标才会出现。
- 网络失败时保留上一份身份表，已有星标不会被清掉。未登录或更换实例地址时会清掉。

## 文件

| 文件 | 作用 |
|------|------|
| `manifest.json` | MV3 清单 |
| `src/background.ts` | 本地匹配、版本检查、星标 |
| `background.js` | 上面那个文件的打包结果，扩展实际加载它 |
| `popup.html` / `popup.js` | 弹窗：授权、展示是否已收藏、跳转添加或详情 |
